# Passport Photo Coach (test)

A test web page that coaches someone through taking a New Zealand passport photo in real time: distance, wall gap, head position, expression, lighting and background, then crops the photo to DIA's digital file rules (3:4 JPG, 900-4500 x 1200-6000 px, 250 KB-5 MB).

Everything runs in the phone's browser. Photos are never uploaded or stored. Not a government service; DIA's own online photo checker and a passport officer make the final call.

Uses Google's MediaPipe Face Landmarker (Apache 2.0).
